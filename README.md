<details>
<summary>⚙️ &nbsp;<strong>One-time setup — click to expand <code>snake.yml</code></strong></summary>

<br/>

Create this file at `.github/workflows/snake.yml` inside your `rnrahate/rnrahate` repo.  
It generates the snake SVG from your **real contribution grid** every 24 hours automatically.

```yaml
name: Generate Contribution Snake

on:
  schedule:
    - cron: "0 0 * * *"    # runs daily at midnight UTC
  workflow_dispatch:         # lets you trigger it manually from Actions tab
  push:
    branches:
      - main

jobs:
  generate:
    runs-on: ubuntu-latest
    timeout-minutes: 10

    steps:
      - name: Generate snake SVG
        uses: Platane/snk/svg-only@v3
        with:
          github_user_name: ${{ github.repository_owner }}
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark

      - name: Push SVGs to output branch
        uses: crazy-max/ghaction-github-pages@v3.1.0
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

**After adding the file:**
1. Go to **Actions** tab → select `Generate Contribution Snake` → click **Run workflow**
2. Once it completes, an `output` branch is created with the SVG files
3. The snake will now appear live in your README 🐍

</details>
